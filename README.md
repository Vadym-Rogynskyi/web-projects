# Web Projects

Interactive websites by Vadym Rogynskyi.

| Site | What it is |
|---|---|
| [Road to the 10K](road-to-the-10k/) | A 7-week 10K training plan with a race countdown, pace calculator, weekly checklists and race-day pacing. |
| [Pace Gap Planner](pace-gap-planner/) | An interactive model showing how much pace to cut each week to hit a goal time. |
| [Ten Kilometres Down](ten-kilometres-down/) | A scroll-driven 3D dive through the five ocean zones to the bottom of the Mariana Trench. |
| [First Paycheck Simulator](first-paycheck-simulator/) | Plan a first job's budget and student loan payoff, and see net worth over ten years. |
| [Settle](settle/) | A buy-vs-rent advisor across 70 US cities, sized to your household, income, down payment and time horizon. |
| [Basis](basis/) | A personal and business finance dashboard: import bank CSVs, auto-categorize, chart trends and get recommendations. |
| [Baseline](baseline/) | A junior-and-pro tennis pathway reference with ITF/Tennis Europe/UTR structure and steps to raise your ranking. |
| [Savings Atlas](savings-atlas/) | A savings-goal tracker with progress bars, a monthly-amount calculator and a guide to saving well. |
| [Speakeasy](speakeasy/) | Language roleplay practice by level and scenario, with a vocabulary notebook. (The AI chat works only inside Claude.) |
| [Cadence](cadence/) | A workout logger for any sport with progress charts, load suggestions and training programs. |
| [Habit Ledger](habit-ledger/) | A daily habit tracker: check off what you kept and see what's left. |

Each site is a single self-contained `index.html` file with no build step. Open any of them in a browser, or view them live on GitHub Pages.
